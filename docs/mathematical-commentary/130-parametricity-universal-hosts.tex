\section{Parametricity in arbitrary original hosts}
\label{sec:parametricity-universal-hosts}
The family diagrams described in Section~\ref{sec:parametricity-family-diagrams}
are connected to actual rule occurrences. A local successful execution
alone is insufficient: a template hole can supply the function of an
application while another original hole supplies its argument, or a copied
lambda can have an arbitrary tree of unused sharing branches. These proofs
preserve both configurations and use the original machine transitions.

\subsection{The exposed argument boundary}
\termdef{parametricity-bare-application}
\textbf{Exposed-argument application.} For a closed family graph
$G:*^{r+1}\to\epsilon$, the graph $\operatorname{BareApply}(G):*^{r+1}\to *$
consists of the complete original application edge and $G$, joined at the
function input. Its only output is the application's argument wire. The graph
that supplies the argument is outside this footprint. The first input is the
active application input, and all remaining family inputs keep their original
order. An indexed form selects an arbitrary original member and records the
induced input action.

Leaving the argument exposed lets it belong to another shallow template
occurrence. The complete argument component stays in the common host context;
no argument graph is cut out or assumed to be a member of the same family.
The original beta rule is enabled from the original rooted search history,
which supplies its unchanged stable argument premise.

\subsection{Inverse openings and exact original sources}
\termdef{argument-exposing-beta-frame}
\textbf{Argument-exposing beta frame.} The original application, lambda and
box edges form a three-edge frame. The first frame output is the bound argument;
the remaining outputs are the lambda's free resources. Its opening certificate
identifies the frame with the original opened box body and preserves each
boundary attachment. Inserting the frame in place of an actual opened-body
occurrence constructs a predecessor and a complete opening certificate for
that predecessor. This is geometric evidence for the existing beta rule.

For the large left family, the opened graph is a bare application of the
selected small abstraction to the unchanged callback. Its selected lambda,
application edge and callback make up the opened body. Every edge outside this
body belongs to the remaining original family, the complete original private
tree, or its allocated cell. These components pass unchanged through the
inverse cut. The selected large member is joined to the remaining family;
its private output is attached to input zero of the original tree, and each
other family output stays attached to its original tree input. Joining the
family, whole tree and cell reconstructs the original closed Figure~20 family.

The source occurrence joins that complete family to the original application.
It fixes all external family input coordinates and leaves the argument wire
as its output. Edge coverage distinguishes retained edges from the inserted
frame edges: retained edges are covered by the remaining family, tree or cell;
inserted edges are covered by the application or selected payload. Thus the
source is a full recursive graph isomorphism, not a partial embedding. The
small case uses the same construction with the private reader and bound
weakening as the opened body. The right families have a corresponding source
reconstruction that keeps the same callback and argument boundary.

\subsection{Arbitrary selected family members}
\termdef{parametricity-selected-boundary-action}
\textbf{Selected-member boundary action.} Selecting a family member may
reorder the external inputs and private outputs. The indexed bare application
records this action: it maps the selected input to its image, fixes the active
application input and argument output, and preserves the relative order of all
remaining entries.

The arbitrary private contraction tree is preserved literally. The proof
pulls that tree back along the inverse private-output action, then supplies an
isomorphism from this compensated presentation to the original family with
its original tree. The induced input action agrees on both sides. A genuine
common input-permutation context transports the opening certificates, exact
machine run, intermediate correction and pointed residual together.

\subsection{Opening and read diagrams}
\termdef{parametricity-read-diagram}
\textbf{Opening and read diagram.} This certificate records two original beta
openings, an exact post-opening run on the left, its actual directed correction,
a pointed parametricity residual to the right opening, and the corrected token's
term type. It packages constructed data; it does not introduce a machine rule
or an assumed relation. The small-family case has eight post-opening steps and
uses the proved copying, two garbage-collection and sharing comparisons. The
large-family case has zero post-opening steps and uses the actual remaining-
family parametricity witness.

An actual application edge and its original owning family hole determine a
common-context cut. Its expansion is isomorphic to the indexed bare application
of the actual filling, with the active token and argument output fixed. The
opening certificates lift through this cut, and original rootedness enables
the beta rewrites in the whole host. Exact finite-run lifting preserves the
post-opening step count. The directed correction and its intermediate focus
also lift, so rootedness of the corrected state follows from proved transport
lemmas rather than a new premise.

The large case therefore compares one transition with one; the small case
compares nine with one. The corresponding improvement and overhead inequalities
remain explicit through the universal robustness clauses. Costs are forgotten
only when deriving termination equivalence.

\subsection{Copying, store and other operation overlaps}
For assignment, the actual store tree is preserved, including unused branches;
only the assignment head and its selected store target change. Read and atom
equality retain their complete supplied trees. For copying, the overlap
classification separates a retained complete payload from a shallow family
entry. A shallow entry is handled by the arbitrary-member diagrams and its
original tree; the actual successor is compared with the constructed rewrite.
For beta with a retained function, the whole application/lambda/box frame is
retained and the argument remains a boundary wire, including in deep and mixed
cases. The shallow case extracts the actual application edge and owning family
hole from the original match. It then uses the exact input selected by the
application/function incidence. Pair decomposition supplies the corresponding
literal family diagram at that input, and the common-context cut lifts both
beta steps and the directed residual. This closes the final shallow branch of
the nine-rule dispatch. Full forward and converse robustness now follow for
the original parametricity relation in unrestricted original contexts.
