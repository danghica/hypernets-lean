Absence of project-specific axioms does not discharge a theorem's hypotheses.
Specimen laws and initial lifting remain parameters of the abstract sufficiency
results. They do not appear as named global axioms in the report. In contrast,
the concrete graph constructions explicitly prove the invariant fields needed
to construct their results. Neither fact supplies the missing bridge to a
concrete UAM.

\subsection{Reproducing the Lean and document checks}
The snapshot pins Lean \texttt{4.35.0} in
\leanfile{lean-toolchain}{lean-toolchain} and uses only the bundled \texttt{Std}.
With that toolchain available, run
\begin{quote}\ttfamily
lake build\\
lake env lean Hypernets/Audit.lean\\
lake env lean Hypernets/Graph/Audit.lean
\end{quote}
The script \leanfile{scripts/check.sh}{scripts/check.sh} runs the build and both
audits. Run it using \texttt{bash} with the script path as its argument. It selects
the workspace-local
macOS ARM compiler if present, and otherwise uses \texttt{lake} from the environment.
The audits are checked separately from the root import.

The commentary's source checker recursively scans all Lean modules under
\texttt{Hypernets/}, including nested graph modules, attributed declarations,
noncomputable definitions, abbreviations, and anonymous examples. It verifies
that each declaration has a source-fragment link, all linked ranges are valid,
and each working source file equals the version at the pinned commit. Diagnostic
audit ranges are linked separately. Run it with
\begin{quote}\ttfamily\small
python3 docs/mathematical-commentary/check\_sources.py
\end{quote}
This syntactic coverage check complements the mathematical exposition; it does
not itself check the correctness of English explanations. Source links are
immutable GitHub commit links, so future edits cannot move the referenced proof.

From the commentary project directory, \texttt{make} checks the links, compiles
with \texttt{latexmk}, and exports the PDF to the repository's
\texttt{output/pdf/} directory. The committed PDF can therefore be read without
a TeX installation, and its editable sources and reproduction instructions are
included alongside it.

\subsection{What remains for the paper's concrete theorem}
The following obligations remain before Theorem~6 can be claimed with its original
hypotheses:
\begin{enumerate}
\item Prove a representation theorem relating the typed depth-indexed hierarchy
with explicit binder metadata to the paper's set-based graph-labelled hypernets.
Recursive isomorphism within each fixed depth layer is now proved. Relating
different depth bounds and proving full representation adequacy remain open.
\item Complete the remaining context algebra, including a quotient of host/site
pairs and interchange for independent sites. Nested substitution associativity,
corolla units, quotient three-stage coherence, and sharp composite context
closure are now proved. Site transport between recursively
isomorphic hosts is now proved, together with simultaneous host/replacement
congruence and invariance of quotient substitution and exact freshness.
Global hole-label uniqueness is now preserved under explicit freshness conditions
for arbitrary deep replacement. Exact syntactic inventories and
necessary-and-sufficient freshness are now proved at every finite box depth,
together with the exact fate of a consumed hole label.
\item Concrete focussed hypernets and the state space are now defined. The five coordinate search rules, their determinism, and their forward shallow
context-filling law are proved. Explicit focus insertion, incidence recovery,
term-typing preservation, initial attachment, and realization of search endpoints
as hole-free focussed states are now proved. Complete erasure of arbitrary
focussed states and its inverse laws modulo isomorphism, and identify the search
relation with the paper's contextual graph rewrites. Define substitution and
compute transitions, rootedness, and refocusing. Prove
the structural laws under the paper's determinism and refocusing hypotheses.
The state space and boundary predicates alone do not define that machine.
\item Define concrete pre-templates, specimens, quasi-specimens, output-closure,
input-safety, and robustness, with the paper's typing and context restrictions.
\item Construct the abstract specimen interface from those objects, proving its
rootedness, final-agreement, and context-only traversal laws, including the needed
consequences of Lemma~39. Its initial/final boundary argument is now proved for
finite fillings; connecting concrete specimens to those fillings remains open.
Prove the safety and robustness bridges and initial lifting for concrete
observations. Initial states can now be constructed; the missing part of
initial lifting is their concrete context/specimen membership.
\item Instantiate the two checked contextual sufficiency results. Only this
last instantiation with all concrete obligations discharged yields the target
robustness theorem.
\end{enumerate}
The present milestone proves both the abstract quantitative argument and a
substantial concrete graph and context-calculus foundation. It does not yet establish that all
hypotheses of the former hold for the universal abstract machine.
